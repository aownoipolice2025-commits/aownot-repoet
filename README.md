# ระบบรายงานผลการปฏิบัติ + ผู้บังคับบัญชา สภ.อ่าวน้อย (รุ่นปรับปรุง)

ชุดไฟล์ใหม่แทนชุดเดิม: ฟอร์มข้อมูลหน่วยงานและภารกิจ, **ข้อมูลผู้กำกับ 1 คน + ผู้บังคับบัญชา 2 คน (ชื่อ ตำแหน่ง และรูปถ่าย)**, สร้างภาพ JPG ขนาด **1024×1920** โดยใช้พื้นหลังตำรวจภูธรภาค 7 ที่ผู้ใช้แนบ และส่งข้อความ/ภาพเข้า LINE Group ด้วย Messaging API ผ่าน Netlify Functions.

## มีอะไรเปลี่ยนจากชุดแรก

- `public/index.html` เพิ่มสามบัตรผู้บังคับบัญชาและช่องเลือกรูปในมือถือ
- `public/styles.css` เพิ่มสไตล์บัตรและตัวเลือกภาพแนวตั้ง
- `public/app.js` ออกแบบภาพรายงานใหม่: ผกก. ด้านบน, ผู้บังคับบัญชา 2 ท่านใต้หัวรายงาน, รูปภารกิจ 4 รูป, รายละเอียดและสรุป; มีปุ่มบันทึกรูป/ข้อมูลเจ้าหน้าที่ในเบราว์เซอร์
- `netlify/functions/_shared.mjs` รองรับชื่อ/ตำแหน่งใหม่
- `netlify/functions/submit.mjs` เพิ่มข้อมูลผู้บังคับบัญชาในข้อความที่ LINE ได้รับ
- `public/guide.html` คู่มือรุ่นใหม่แนะนำการเปลี่ยนไฟล์เดิมโดยไม่ล้างค่า LINE
- `docs/report-layout-preview.jpg` ภาพตัวอย่างที่สร้างด้วยหน้าเว็บรุ่นใหม่
- ชื่อ/ตำแหน่งเริ่มต้นใส่ตามข้อมูลที่ผู้ใช้เคยให้ไว้ (โปรดตรวจสอบก่อนใช้งานจริง) **รูปถ่ายผู้บังคับบัญชาทั้งหมดเว้นไว้ให้ผู้ใช้แนบรูปเจ้าหน้าที่ที่ถูกต้อง** ไม่ได้นำภาพของสถานีอื่นมาใช้

## วิธีเปิดใช้งาน

1. เปิด `public/guide.html` หรือ `https://ชื่อเว็บของคุณ.netlify.app/guide.html` เพื่อดูคู่มือภาษาไทย
2. หากเป็นเว็บไซต์ใหม่ ให้แตก ZIP แล้วอัปโหลด **ไฟล์ทั้งหมดภายในโฟลเดอร์โครงการ** ลง GitHub และเชื่อม Netlify เพื่อ Build/Deploy
3. หากมีเว็บไซต์รุ่นก่อนบน GitHub: อัปโหลดไฟล์โครงการรุ่นนี้ทับไฟล์เดิม แล้วรอ Netlify Deploy ใหม่ **ไม่ต้องเปลี่ยน URL เว็บไซต์, Webhook URL, หรือ Environment variables เดิม** หากยังเป็นไซต์เดิม
4. กรอก LINE API secrets ใน Netlify (ถ้ายังไม่เคยตั้ง): `LINE_CHANNEL_ACCESS_TOKEN`, `LINE_CHANNEL_SECRET`, `REPORT_PIN` (>=8 ตัวอักษร), `LINE_PAIR_CODE` (>=8 ตัวอักษร)
5. ตั้ง Webhook: `https://ชื่อเว็บของคุณ.netlify.app/.netlify/functions/line-webhook`; เชิญ LINE OA เข้ากลุ่ม ส่ง `เชื่อมรายงาน <LINE_PAIR_CODE>` 1 ครั้ง
6. ในหน้าเว็บไซต์ใส่ข้อมูลชื่อ/ตำแหน่งผู้บังคับบัญชา เลือกภาพบุคคลจริง กด **บันทึกข้อมูลผู้บังคับบัญชาไว้ในมือถือเครื่องนี้**
7. กรอกภารกิจ + แนบภาพ (สูงสุด 4 ภาพ), กดสร้าง/ดาวน์โหลด JPG หรือส่งเข้า LINE เมื่อเชื่อมสำเร็จ

## เก็บข้อมูลอย่างไร

- ชื่อ ตำแหน่ง และรูปผู้บังคับบัญชาเก็บใน **localStorage ของเบราว์เซอร์เครื่องนั้น** เมื่อกดบันทึก และไม่ถูกอัปโหลดไปยังเซิร์ฟเวอร์จนกว่าจะกดส่งรายงาน
- ร่างภารกิจเก็บใน **sessionStorage**; หลังปิดเบราว์เซอร์ร่างอาจหาย
- รหัสส่งรายงาน **ไม่จัดเก็บ** บนเครื่อง; รหัส LINE และรหัสลับอื่นเก็บเฉพาะใน Netlify Environment variables
- ภาพรายงานเมื่อส่ง LINE ถูกเก็บใน **Netlify Blobs** และมีลิงก์สาธารณะเฉพาะรายการเพื่อให้ LINE โหลดภาพได้ ผู้มีลิงก์สามารถดูภาพได้ (ควรใช้เฉพาะข้อมูลเผยแพร่ได้)

## ขอบเขต

ตัวระบบเป็นเว็บไซต์ช่วยผลิตภาพ/ส่งแจ้งเตือน ไม่ใช่ระบบทะเบียนคดีหรือระบบทางราชการที่ได้รับรอง การส่งจริงต้องตั้งค่าและทดสอบกับบัญชี LINE OA ของหน่วยงานเอง ห้ามนำข้อมูลลับหรือรูปบุคคลที่ไม่ควรเปิดเผยไปเผยแพร่ และควรให้ผู้มีอำนาจตรวจสอบชื่อผู้บังคับบัญชา/ตำแหน่งก่อนใช้งาน.

## ทดสอบโค้ด

Node.js >=22.12, `npm install`, `npm test`, `npm run build`. ต้องใช้ Netlify live functions และข้อมูลบัญชี LINE จริงเพื่อทดสอบการส่ง LINE.
